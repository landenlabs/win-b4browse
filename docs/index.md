# B4-Browse

Check that your network and Windows PC are in a safe state **before** you browse.

- **Network safety:** spots rogue proxies, DNS hijacking and spoofing, and suspicious router or
  resolver settings.
- **Recent changes:** lists programs, extensions, processes, services, drivers and startup
  entries that changed recently but don't line up with a Windows update.
- **Runs locally:** no account, no telemetry. See the [privacy policy](privacy.html).
